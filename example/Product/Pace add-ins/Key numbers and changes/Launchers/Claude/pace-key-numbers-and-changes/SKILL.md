---
name: pace-key-numbers-and-changes
description: Launcher for the Key numbers and changes add-in in Pace by SBR. Use when the owner hands over files and asks what changed in their key numbers.
---

This launcher only points to the add-in and adds no rules of its own. In the owner's Pace folder, open `Pace.md` and find the Key numbers and changes line in its add-in index. Open the file that line names, which is `Product/Pace add-ins/Key numbers and changes/ADD-IN.md` or the owner's customised copy, and follow it for this request. If Key numbers and changes is not in the index, it is off: say so, and switch it on only when the owner says to.
