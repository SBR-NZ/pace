---
name: pace-contracts
description: Launcher for the Contracts add-in in Pace by SBR. Use when the owner asks to set down or read back a contract for a workbook or recurring job.
---

This launcher only points to the add-in and adds no rules of its own. In the owner's Pace folder, open `Pace.md` and find the Contracts line in its add-in index. Open the file that line names, which is `Product/Pace add-ins/Contracts/ADD-IN.md` or the owner's customised copy, and follow it for this request. If Contracts is not in the index, it is off: say so, and switch it on only when the owner says to.
