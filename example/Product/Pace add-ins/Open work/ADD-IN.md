# Open work

**Purpose:** Make a complete list of open work, or of everything recorded in one year.

## When to use it

When the owner asks for a full list, such as "what is still outstanding?", "list everything open for the bakery project" or "everything we recorded in 2025". A quick status answer about one item does not need it: this add-in is for a deliberate, complete list.

## What it needs

- The scope: all open work, one project, or one person.
- For a year list, the year and which date decides it: when an item was recorded, when it was due or when it was done. Ask if this is not clear.

## Steps

1. Agree the scope and, for a year list, which date decides the year.
2. Search the whole of the relevant record. If results come back in pages, follow every page. Follow [Records and source evidence](../../Help/records.md) for what counts as a complete listing.
3. If the search could not cover everything, for example a file that would not open or a listing that stopped early, say so first and present the list as partial. Never say "nothing is outstanding" after a partial search.
4. Use each item's current state. Done, cancelled and disputed items are shown as what they are. An item recorded two different ways is shown once, with both accounts.
5. Where a record was corrected, use its latest version. Show earlier versions only when the owner asks for the history.
6. Give the count first, then the list, grouped by project (or by month for a year list), with each item's due date, the person responsible and its state.

## What it gives back

The count and the list in chat, with a line saying what was searched and whether the list is complete. If the owner wants the list kept, it is a dated view, not a record: see [Assistants and dated views](../../Help/hosts-and-views.md).

## Limits

- These steps apply only while making this list. Nothing here carries over to the rest of the chat.
- The list changes nothing in the record: it does not mark anything done, create a reminder or send a hand-off.
