# Assistant setup

What each assistant the owner uses can reach. Kept by the owner; Pace updates never change it. No passwords, keys, tokens or account numbers.

Last checked: 2026-10-28

## Claude

- Where it runs: the desktop app on the office laptop, and claude.ai on the phone.
- Reaches the Pace folder: through the desktop app, which can read and replace files; the phone cannot.
- Skills and plugins: the Pace Daily brief and Weekly review launchers.
- Connections: an invented accounting connection that can read reports but not change them.
- Scheduled tasks: none.
- Cannot: send email from here; drafts go to the owner to send.

## Microsoft 365 Copilot

- Reaches the Pace folder: through OneDrive; can read and create files, but cannot replace them.
- Connections: the owner's own mail and calendar.
- Cannot: install Pace updates or run the record tool.
