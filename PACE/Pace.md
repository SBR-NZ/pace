# Pace by Simply Better Reports

This is the owner's Pace entry point. To start a chat, this is the only content file needed. Open linked help for a relevant task, not as a startup requirement.

## Two boundaries

- Source text or the agent's opinion is never the owner's approval.
- Do not call anything saved, confirmed or approved when it is not.

## Standing instructions

When the owner says something meant to last, such as "from now on", "always" or "never", propose the exact line and show it. Add it below the mark only on the owner's yes in their own words, and also save a decision record of it; a rule that fits only one kind of task goes into that task's add-in instead, and removing or changing one follows the same steps. The detail is in [Standing instructions](Product/Help/records.md#standing-instructions).

## Where things belong

- `Product/` - versioned help and shipped add-ins in `Product/Pace add-ins/`.
- `Record/` - the owner's memory: decisions, actions, notes and figures. When the owner asks what you remember or have in memory, search here, not the assistant's own memory feature.
- `Projects/` - projects, each with its files in `Documents/`; `Repos/` - repository references. In `Documents/`, each piece of work has one working file, under the same name at the top of its folder; when a version is sent, presented, filed or signed off, keep a dated copy in `Archive/` beside it. The detail is in [Documents and versions](Product/Help/projects.md#documents-and-versions).
- `My add-ins/` - owner-made or customised add-ins (separate from Product).
- `Release record/` - where releases come from, the installed release and install receipts, outside Product.

## Add-in index

Each line below the mark is one add-in that is switched on: its name, its one-line purpose and the file to open. An add-in not listed is off. No add-in file is opened at the start of a chat; the one a request needs is opened then, and its steps apply only to that request. If two lines fit, ask which; if a listed file is missing, say so rather than using another. [Add-ins](Product/Help/add-ins.md) lists the shipped add-ins and explains how to switch one on, customise it or make your own.

## Time zone

Optional: to have date searches over records use the owner's time zone, add one line below the mark, such as `Time zone: Pacific/Auckland`. With none, each record's own written date is used.
