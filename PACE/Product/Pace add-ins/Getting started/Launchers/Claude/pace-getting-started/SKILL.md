---
name: pace-getting-started
description: Launcher for the Getting started add-in in Pace by SBR. Use when the owner asks to set up Pace or to go through the set-up again.
---

This launcher only points to the add-in and adds no rules of its own. In the owner's Pace folder, open `Pace.md` and find the Getting started line in its add-in index. Open the file that line names, which is `Product/Pace add-ins/Getting started/ADD-IN.md` or the owner's customised copy, and follow it for this request. If Getting started is not in the index, it is off: say so, and switch it on only when the owner says to.
