---
name: pace-project-overview
description: Launcher for the Project overview add-in in Pace by Simply Better Reports. Use when the owner asks where a project, every project or one person's work stands.
---

This launcher only points to the add-in and adds no rules of its own. In the owner's Pace folder, open `Pace.md` and find the Project overview line in its add-in index. Open the file that line names, which is `Product/Pace add-ins/Project overview/ADD-IN.md` or the owner's customised copy, and follow it for this request. If Project overview is not in the index, it is off: say so, and switch it on only when the owner says to.
